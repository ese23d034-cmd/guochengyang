# 提交说明

- **项目**：云谷鲜米粉 ERP 供应链与 FI/CO 集成（Project RiceFlow）
- **提交范围**：整个 yungu.docx 场景的全模块实现
- **覆盖模块**：SD 销售 / PP 生产 / MM 采购 / FI 财务 / CO 管理会计 / HCM 人力资源
- **技术栈**：Python 3.10+ / SQLite / 标准库 REST API（零第三方依赖）

## 一、作业内容

本项目实现了一条完整的 ERP 业务链：

```text
HCM 排班/权限
  → SD 门店 POS 销售
  → 门店库存低于补货点自动要货
  → 企业团餐订单
  → PP MRP（多级 BOM 展开、净算、批量、提前期）
  → MM 采购订单/冷链收货
  → PP 生产订单/发料/报工/成品入库
  → SD 工厂到门店/企业客户配送
  → SD 次日 POS
  → FI 自动凭证/试算平衡/利润表
  → CO 门店利润中心/单品毛利
```

## 二、快速验收

用 VS Code 打开项目根目录，选择 Python 3.10+ 解释器，按 `F5` 选择：

```text
ERP：运行全模块演示
```

或在终端执行：

```powershell
py -3 run_full_demo.py
py -3 -m unittest discover -s tests -v
```

- 30 张业务凭证 + 1 张期初凭证 + 2 张门店费用凭证；
- 试算平衡；
